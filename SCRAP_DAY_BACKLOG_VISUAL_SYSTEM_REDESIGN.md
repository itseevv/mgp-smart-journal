# Scrap the Day Visual System Redesign Backlog

## Why this is deferred

The current UI is functional and useful for product flow validation, but it is not yet aligned with the final lifestyle, premium, editorial brand direction.

Full redesign should happen after Phase 5A Daily Export is implemented, because export will clarify the reusable visual system across app views and shareable artifacts.

## Future redesign scope

1. Journal background / leather theme system

- Around 10 journal leather/background designs.
- Admin selects the journal's leather/background before activation.
- Selected theme controls the user-facing NFC page background.
- Export layouts should reuse the same theme source.
- Current theme tokens/backgrounds are placeholders.

2. Admin theme selection

- Add an admin field for journal theme/background.
- Theme is selected before journal activation.
- User does not select the theme in MVP.

3. App + export shared visual components

- Daily Memory Stamp app view.
- Daily export poster.
- Monthly Sheet app view.
- Monthly export poster.
- Shared paper mat.
- Shared leather background.
- Shared stamp-edge frame.
- Shared MGP logo placement.

4. Leather / paper material polish

- Replace the current rough leather simulation.
- Tune paper texture.
- Tune color contrast across 10 journal themes.
- Ensure accessibility and readability.

5. Stamp-edge polish

- Finalize perforation edge style.
- Tune large, medium, and small variants.
- Make sure it looks physical but not childish.

6. Typography and spacing

- Refine editorial serif scale.
- Establish a mobile-first rhythm.
- Avoid a functional dashboard feeling.

7. Brand mark / MGP logo

- Use the uploaded MGP logo.
- Place it subtly on export assets.
- Private app view should remain user-first, not brand-heavy.

8. Export-specific visual design

- Daily 9:16 export.
- Monthly 9:16 export.
- No journal name in the first version.
- No "Private by nature" in export.
- MGP mark only, no "powered by."

## Not part of the current patch

- Do not implement admin theme selection now.
- Do not upload theme assets now.
- Do not redesign all components now.
- Do not implement export now.
